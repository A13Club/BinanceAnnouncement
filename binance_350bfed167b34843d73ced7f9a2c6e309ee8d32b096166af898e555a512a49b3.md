Fellow Binancians,
Binance Wallet, together with BNB Chain, is jointly hosting the Agent ID Hackathon. Developers may participate and explore innovative use cases for Agent ID in on-chain applications. Agent ID is the on-chain name of an Agentic Wallet, taking the form of name.ai. Each user can claim only one Agent ID, and it is non-transferable. Participating projects must be deployed on BNB Chain and actively use Agent ID. Both new and existing projects are eligible to submit.

Project names, token names, and domain names must not use "Binance" / "BNB" to impersonate the official brand.No collection of sensitive credentials. Projects must not collect users' seed phrases, private keys, API secrets, or pairing codes.Participating projects must not promise returns externally. Terms such as "passive income" or "automatic money-making" are prohibited.Products involving trading must display risk warnings on the page.Agent ID must not be packaged as a tool for "looking up other people's wallets by name."Binance Wallet reserves the right to disqualify projects exhibiting abnormal behavior, including but not limited to malicious volume manipulation, illegitimate mass account registration for interactions, or other activities showing signs of market manipulation.

About Agent OS:
Binance Agent OS is a developer platform under the Binance Intelligence architecture that connects compatible AI applications and Agents to Binance-supported features through user-controllable permissions.
Binance Agent OS integrates Binance APIs, Binance Wallet Agentic Hub, Binance x402, Binance Skill Hub, and support for the Model Context Protocol (MCP) into a more cohesive ecosystem serving developers, users, and the broader industry. This release reflects Binance's commitment to building infrastructure for agentic crypto experiences and lays the foundation for continued expansion of agentic skills, wallet capabilities, and developer tools.
